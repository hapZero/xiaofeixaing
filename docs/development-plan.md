# 小飞象产品开发计划

## 产品原则

- 前台创作流程对齐小云雀：剧本大纲 → 资产库 → 分集视频 → 分镜编辑 → 合成导出。
- ComfyUI 是可替换的执行适配器；节点与 JSON 只在管理员配置页出现，不进入创作者主线。
- 角色形象、角色形态、场景和关键道具是项目级资产；音色与环境声按所选视频方案按需配置。
- 所有生成均以任务形式执行，必须可追踪、可重试、可恢复、可查看历史版本。
- 商用数据使用服务端数据库与对象存储，浏览器状态只用于临时交互。

## 已确认的商用技术栈

- Web：React、TypeScript、Next.js 兼容前端。
- 业务 API：Node.js、NestJS。
- 数据库：PostgreSQL、Drizzle ORM。
- 任务系统：Redis、BullMQ、独立 Worker。
- 媒体：S3 兼容对象存储，支持 OSS、COS、MinIO 或 R2。
- GPU 执行：Spark 上的 ComfyUI。
- 实时进度：SSE 为主，必要时使用 WebSocket。
- 合成：FFmpeg。
- 认证：手机号验证码、短期 Access Token、可轮换 Refresh Token。
- 监控：结构化日志、Sentry、OpenTelemetry。

## 与技术栈一致的开发顺序

### 1. 工程与运行边界

- 建立 monorepo：`apps/web`、`apps/api`、`apps/worker`、`packages/domain`、`packages/contracts`、`packages/ui`、`packages/comfyui-client`。
- 保留当前原型作为 Web 产品基线，不再把新业务堆入单页文件。
- 建立统一配置、错误码、日志、校验、测试和代码规范。

### 2. 核心基础设施

- 建立 PostgreSQL 数据库、迁移和 repository 层。
- 建立 Redis、BullMQ 队列和 Worker 生命周期。
- 建立 S3 媒体存储适配器、上传与签名访问。
- 建立本地 Docker Compose 开发环境和环境变量规范。

### 3. 账户与项目纵向闭环

- 手机号验证码登录、会话续期、退出和服务端权限校验。
- 项目创建、项目列表、项目设置、自动保存和用户数据隔离。
- 用这一条闭环验证 Web → API → PostgreSQL → Redis → Worker 的完整链路。

### 4. ComfyUI 执行底座

- 工作流能力注册、输入输出映射和版本管理。
- API 创建任务，BullMQ 排队，Worker 调用 Spark/ComfyUI。
- 进度回传、超时、取消、重试、幂等、失败恢复和结果入库。

### 5. 剧本与资产

- 上传/粘贴剧本、AI 生剧本、分集编辑、资产拆解和剧本锁定。
- 角色与多形态、固定音色、场景、道具、素材、确认状态和项目画布。

### 6. 分镜、视频与声音连续性

- 分镜脚本、资产引用、片段版本、历史版本和批量生成。
- 角色音色引用、口型同步、场景声音场、环境声连续和混音策略。

### 7. 合成与交付

- FFmpeg 单集合成、字幕、配乐、整剧导出、下载和发布记录。

### 8. 商用保障

- 权限、审计、限流、监控、告警、备份和数据恢复。
- 运营后台、用量统计；收费模块按产品决定后接入。

## 当前开发位置（按可验证结果记录）

- 已可用：本地账号项目、剧本编辑、资产和分镜数据持久化、自由画布持久化。
- 已实现：正式环境以平台认证头为账号权威身份，本地开发使用隔离账号；进入后刷新会重新向服务端验证账号再恢复工作台，顶部显示真实姓名和邮箱，并提供平台退出登录，不再使用写死头像与姓名。
- 已可用：读取 Spark 当前工作流目录、统一下拉选择、版本化执行版、输入输出映射、同一兼容工作流复用和每个适配器独立真实测试。
- 已实现生产准入：保存绑定不再等于商用可用；只有最近一次真实测试成功的执行版才进入生产方案，工作流或字段映射变更会自动失效旧验证。
- 已可用：ComfyUI 节点事件、节点内进度、输出读取和媒体归档；角色标准图、分镜首帧、图生视频已有真实任务接口。
- 已可用：LLM 服务连接的加密保存与真实连通测试；AI 生成剧本会真实调用已配置模型并保存分集。
- 已实现：上传剧本与 AI 剧本统一调用 LLM 形成故事蓝图、角色多形态、场景、道具、人物关系和片段-分镜草案；多集上传文件会落为真实分集记录，不再使用正则提取或拆镜。
- 已完成结构纠偏：生产引擎不再显示固定十能力清单，改为视觉资产、片段视频、可选声音增强三类生产方案；分镜只保存创作意图，执行时依据当前配置动态选择原生有声或独立配音口型路线。
- 已建模：项目资产、角色多形态、固定音色、场景声音场、Episode → Segment → Shot、对白行、音轨、镜头版本和片段生产计划。
- 已实现：角色每个形态、场景和关键道具均可提交真实 ComfyUI 任务，显示节点进度，回写稳定项目资产并保留生成版本；所有视觉资产真实就绪后才能进入片段生产。
- 已实现：片段可一次提交包含多个分镜和时间信息的完整导演指令；缺少起始分镜时自动先生成首帧，完成后继续整段视频；结果回写片段、保留版本，页面重开后可恢复正在执行的任务。
- 已实现：分集页面可建立持久批次，由后台执行器依次推进每个待生产片段及其必要声音阶段，页面只观察 Spark 当前节点进度；本地常驻 runner 与正式定时触发器共享带原子租约的状态机，关闭页面后继续执行，失败会落到批次记录并保留此前完成片段，可从失败位置重新开始。
- 已实现：工作引擎页面通过持久心跳显示独立批次执行器是否真实在线，并直接探测 FFmpeg 媒体处理器；只启动网页服务时会明确提示后台任务不会推进，避免把“页面可打开”误判为“生产链路可用”。
- 已实现：后台执行器会统一协调全部活跃生成任务，不论任务是从资产弹窗、单个分镜、片段生产还是批量生产提交；创作者离开原页面后，ComfyUI 节点进度、成功媒体归档、输出缺失和队列丢失仍会收敛到持久状态。
- 已实现：分镜参考和片段生产只接受创作者已锁定的角色形态、场景与道具；仅有媒体文件但仍待确认的资产会明确阻断生产。任何已引用视觉资产被重做或取消锁定时，相关分镜首帧、镜头视频、片段当前版本和整集当前成片指针都会失效，历史版本保留但不能被静默复用。
- 已实现：不支持整段多分镜指令时，备用路线会依次生成每个镜头，再由内部媒体服务合成连续片段；用户仍只操作“生成片段”。
- 已实现：片段重做保留全部历史版本，编辑器可切换、播放和下载任一版本；正式视频、逐镜合成片段和整集合成在归档前执行真实时长校验，0 秒或严重短于目标时长的结果会持久化为失败而非成功。
- 已实现：ComfyUI 提交中断和 Spark 队列丢失会落为可理解的失败；FFmpeg 片段合成、声音混合与整集合成超过任务租约会自动标记中断并释放重试，整集页面可在刷新后恢复任务状态。整集历史版本可切换预览，并下载对应版本的成片和字幕。
- 已实现：非原生有声路线会按对白行引用锁定角色音色，依次执行配音、可选连续环境声、FFmpeg 混音与口型同步；原生有声路线直接复用视频结果。声音任务、音轨、媒体结果和失败信息均持久化并可恢复。
- 已实现：分集页面以片段时间线预览本集；全部片段就绪后，内部媒体服务统一规格并用 FFmpeg 合成整集 MP4。导出时可选择短剧醒目、电影简洁、极简细字三种字幕样式，字幕会真实烧录进成片，同时保留可下载 SRT；整集保存为可切换历史版本。
- 已实现：整集合成与整剧交付提交后立即返回并转入后台媒体任务，页面关闭或刷新后继续按持久状态展示进度和结果；后台归档前会核对提交时冻结的片段/分集版本，输入已变化的过期任务只记录失败，不覆盖当前成片或交付状态。
- 已验证：项目内置的静态 FFmpeg 二进制已完成真实双音轨混音和横竖屏片段整集合成冒烟测试，不依赖本机 Homebrew 的 FFmpeg 状态。
- 已实现：自由画布不再自动注入示例人物与剧情；已有项目会从真实角色、场景、道具、片段和生成结果建立节点图，新项目从空白灵感开始。图片/视频/音频上传进入对象存储，确认画布后节点与连线会落为同一套项目资产、分集、片段、分镜和资产引用。
- 已验证：临时自由画布项目经“灵感 + 角色 + 场景 + 片段”连线真实落库后，得到 1 个角色、1 个场景、1 个片段、1 个分镜和 2 条资产引用；测试项目随后已清理。
- 已修复：本地 D1 历史毫秒时间戳已迁移为秒级，项目时间和排序不再落到异常未来年份。
- 尚待真实模型验收：当前账号尚未配置 LLM 地址、模型和 Key，因此剧本结构化链路已完成编译与契约测试，但还没有用真实项目跑通结果质量。
- 尚待真实媒体验收：当前示例项目的角色、场景和道具尚未生成真实标准图，因此片段任务会正确阻断；需要完成一次实际资产生成后再验证 Spark 输出质量和多分镜遵循度。
- 已实现：视觉质检作为独立可选模型能力，不与剧本 LLM 混用。小飞象可从真实片段视频抽取六个时间点形成联系宫格，先做资产、时长、角色形态与场景引用的结构检查，再由支持图片输入的模型辅助检查角色、场景、动作衔接和分镜覆盖；AI 报告与创作者确认都保存到当前片段版本。整集合成必须有创作者确认，结构错误不可绕过，但未配置视觉模型不会卡死主线。
- 已实现：整剧批量交付以各集“当前版本”为不可变快照，真实读取 MP4 与 SRT 后生成 ZIP。交付包内含分集成片、字幕和 JSON 清单，清单记录版本、大小及 SHA-256 校验值；导出任务、失败原因和历史下载均持久化，服务重启造成的中断可释放后重试。
- 尚未完成：面向外部发行平台的发布连接与发布记录；整剧文件交付、历史记录和再次下载已经可用。
- 尚未完成：手机号验证码正式供应商和最终商用部署；当前本地 D1/R2 仅用于产品链路开发，PostgreSQL/Redis/S3 是商用权威数据层。

自由画布已经改用成熟节点画布底座，分镜编辑器已经重构为以片段为中心的生产工作台，并继续复用统一的项目资产、生成任务、审片、声音、合成和交付能力。当前开发任务是沿三种入口对真实媒体验收：先完成项目视觉资产生成，再验证多分镜片段遵循度、创作者审片、整集合成和整剧交付。

## 代码约束

- 页面只负责组合，业务逻辑放在 feature/service 中。
- 数据访问只通过 repository，外部服务只通过 integration adapter。
- 禁止在 UI 中直接调用 ComfyUI。
- 禁止把项目数据保存为浏览器端权威状态。
- 状态与错误码使用集中定义，避免散落字符串。
- 核心服务必须有测试；每次提交必须通过 lint、build 和 test。
