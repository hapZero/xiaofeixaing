# 小飞象产品主线

## 唯一验收目标

创作者输入或编辑剧本后，能够得到一集可预览、可局部重做、声音连续并可导出的短剧。任何页面、按钮、工作流或数据表，不能证明自己服务于这条链路，就不进入主导航。

## 已核对的小云雀交互事实

- 项目以“剧本大纲 → 资产库 → 分集视频”推进。
- 资产库是项目级的：角色可以有多形态、出现集数和固定声音；场景和道具同样沉淀后复用。
- 分集视频进入单集后，用户操作的生产单位是“片段”；一个片段包含多个镜头，并形成连续的视频结果。
- 单镜头仍可编辑和重做，但不是用户完成整部短剧时反复手工执行工作流的主路径。

以上是从产品界面确认的交互事实。小云雀未公开的模型、调度和声音算法不作为已知事实；小飞象用自己的商用工程实现同等的创作结果。

## 小飞象生产主线

```text
剧本/大纲
  → 分集、场次、角色、对白和道具结构化
  → 项目资产确认（角色多形态 + 场景标准图 + 必要时配置固定音色）
  → 每集拆成片段，每个片段包含多个镜头
  → 小飞象根据已配置生产方案生成包含多个镜头的连续片段视频
  → 片段级连续性检查和局部重做
  → 小飞象合成片段（画面 + 对白 + 环境音 + 字幕）
  → 单集时间线、整集预览和导出
  → 冻结各集当前版本并生成可校验的整剧交付包
```

## 职责边界

小飞象自身负责：剧本理解、资产引用、片段和镜头编排、依赖调度、版本、失败恢复、质量检查、字幕、音轨混合、FFmpeg 合成和导出。

片段有两种可替换执行方式，但前台始终只呈现“生成片段”：支持多分镜指令的视频模型可一次生成整个连续片段；不支持时，小飞象在后台生成各镜头并用媒体工作器合成。执行方式是生产方案细节，不要求创作者手动选择或逐个运行工作流。

底层生成适配器负责提供图像、视频和必要声音结果。角色图、场景图、分镜参考图、原生有声视频、静音视频、配音、口型与环境声只是可组合的输入输出契约，不是前台固定步骤，也不是要求用户全部配置的清单。

ComfyUI 只是其中一种生成能力适配器。创作者不需要理解节点，也不需要为“剧本拆解”或“单集合成”额外提供 ComfyUI 工作流。

## 当前 Spark 工作流来源审计（2026-07-22）

Spark 当前保存的工作流只是候选执行来源，数量不等于小飞象的产品能力，也不构成创作主线。按文件名和已同步执行版只能做候选判断，必须绑定到明确输入输出契约并通过真实测试后才可进入生产方案：

- 已绑定并实测链路：人物一致性生成器 → 角色标准图；文生图 → 分镜首帧；LTX 图生视频 → 图生视频。
- 可作为候选、尚未完成绑定测试：多主体视频生成器、首尾帧视频、LTX 图生视频+音频口型、LTX 图生视频+音频参考、多图输入生成图片。
- 辅助能力，不属于主线必备工作流：视频换角色。
- 当前目录没有明确对应：固定角色音色生成、环境声音场生成。

小飞象对外只呈现三类生产方案：视觉资产生成、片段视频生成、可选声音与氛围增强。片段视频只需要至少存在一条完整路线：原生有声视频，或视频生成加固定音色与口型同步。多人、首尾帧等能力属于按镜头自动选用的优化适配器。

## 生产准入规则

- 角色或场景只有名称、没有真实媒体文件时，禁止显示为“资产已就绪”。
- 工作流只有绑定、没有通过真实输入输出测试时，不能标记为商用可用。
- 工作流执行版或输入输出映射发生变化时，旧测试自动失效，必须针对新版本重新测试。
- 片段缺任一引用资产或当前执行方式所需生成能力时，禁止显示“开始生产”；只有采用分镜合成路线时才要求内部合成器就绪。
- 片段生产必须生成可追踪任务；任务按依赖执行，显示当前节点、节点进度、重试和最终结果。
- 分集可以建立持久化批次，由带原子租约的后台执行器按片段顺序复用已经完成的结果，只补齐待生产视频和必要声音；关闭页面后继续推进，重新打开时读取当前片段，任一片段失败时停在准确位置并保留前面成果。
- ComfyUI 提交中断、Spark 队列丢失以及 FFmpeg 服务重启必须形成明确失败记录；超过租约的媒体任务自动释放，允许安全重试，不能永久显示“执行中”。
- 失败只重做受影响的镜头或音轨，不覆盖此前可用版本。
- 正式视频在归档前必须通过非空与时长检查；片段重做保留历史版本并允许切换预览、下载。
- 整集合成前，每个当前片段版本必须由创作者审看并明确确认。系统会先强制执行真实文件、必需资产和时长等结构检查；可选的视觉模型可从真实视频抽取多个时间点，辅助核对角色形态、场景、动作衔接与分镜覆盖。AI 质检报告与创作者决定都保存到当前版本，结构错误不可人工绕过；未配置视觉模型不应阻断创作者确认与整集合成。
- 整集合成和整剧交付必须在请求返回后继续作为后台媒体任务执行，页面关闭后仍可读取进度、失败和结果；任务提交时冻结输入版本，完成前再次校验，过期任务不得覆盖用户后来选择的片段或分集版本。
- 整剧交付只读取每集已经持久化的当前成片和字幕；导出时冻结版本快照，生成包含文件大小与 SHA-256 的交付清单，并保留可恢复、可再次下载的历史记录。
